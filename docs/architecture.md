# 技术架构与边界

## 个人原型（未公开核心代码）
- Edge / Chromium 浏览器扩展：Manifest V3，弹窗 + 配置页 + 后台 Service Worker + 用户主动触发的页面脚本。
- 简历资料：结构化中英文字段、多段教育、工作和研究项目；本地保存。
- 招聘任务：单链接、Excel 导入、用户手动登录与验证码、表单检测、缺项提问、手动提交、状态登记。
- 不绕过登录，不自动批量点击提交。

## 公开 demo（本仓库）
- `demo/index.html`：纯本地模拟 UI，全部使用虚构数据；不上传数据。
- `src/workflow.sample.js`：演示岗位匹配、upsert 和缺失字段检测的纯函数。
- `src/workflow.test.js`：Node.js 自包含单元测试。

## 开发中的流程
```mermaid
flowchart LR
  A[单链接或 Excel] --> B[职位队列]
  B --> C[用户登录并打开申请页]
  C --> D[字段匹配]
  E[本地简历资料] --> D
  D --> F{缺少信息?}
  F -->|是| G[提问]
  F -->|否| H[用户核验]
  G --> H
  H --> I[用户自行提交]
  I --> J[本地投递记录]
```

## 公开商业版必须完善的部分
- **权限**：缩小广泛的 host permissions，优先按用户操作授予权限。
- **隐私**：隔离不同用户数据，提供删除/导出与清晰的隐私政策。
- **兼容**：SPA、跨域 iframe、动态下拉、多个经历、附件上传、页面更新与断点续跑。
- **质量**：自动化回归测试和错误恢复，拒绝未确认的自动提交。
- **商业化**：许可证、收费授权、退款政策、安全更新及客服支持。

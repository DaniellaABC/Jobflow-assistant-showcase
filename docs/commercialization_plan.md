# 产品化与商业化计划

此文档是产品路线草案，不代表软件已正式上市或价格经过市场验证。

## 产品定位
为求职者提供简历复用、职位队列管理、缺失信息提问和半自动申请辅助，不宣传无人值守投递、验证码绕过或全平台兼容。

## 版本路线
1. **Portfolio Demo** — 本仓库：脱敏界面、演示算法、测试及设计文档。
2. **Private Beta** — 多用户首次配置、清理和导出本地资料、按需授权的浏览器权限。
3. **Public Beta** — 测试常见招聘平台、审查个人信息处理与应用商店规范。
4. **Commercial Release** — 许可证、更新渠道、用户支持、退款规则和安全维护。

## 收费实验（仅供讨论）
- Free：有限的简历资料与岗位管理。
- Pro：完整资料、多段工作经历、链接批次、缺项提问与投递记录。
- 先对小规模真实用户开展付费意愿测试；不要提前保证支持全部招聘网站。
- 若涉及云同步或 AI API，再核算经常性运营成本后决定是否订阅。

## 代码仓库管理
- **公开仓库**：展示技术能力，使用完全虚构的数据。
- **私有仓库**：未来的完整产品源代码和安装/授权系统，但也不得把任何用户的真实简历、cookie、密钥或会话记录提交进去。

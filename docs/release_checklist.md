# 面向其他用户的正式发布验收清单

- [ ] 新用户首次安装，不必修改代码即可导入自己的简历
- [ ] 不包含开发者真实姓名、联系方式、简历、聊天记录或凭据
- [ ] 用户简历数据导入、导出与一键删除
- [ ] 只填确定字段，缺失项提问，不擅自猜测
- [ ] 默认保留网页已填写内容，遇错不自动关闭标签页
- [ ] 用户自己处理登录、验证码、附件确认和最终提交
- [ ] 在真实招聘系统进行跨平台回归测试
- [ ] 收窄扩展权限并审计网页脚本
- [ ] 扩展权限、存储与任何数据共享均向用户明示
- [ ] 提供隐私政策、服务条款、退款规则和反馈渠道
- [ ] 提供明确安装步骤、更新与卸载方法
- [ ] 使用虚构数据制作商店截图和演示视频
- [ ] 代码静态检查与单元测试通过
- [ ] 公开展示仓库与私有商业仓库严格分开
- [ ] 通过浏览器扩展平台官方审核后再宣称上架
